Turn any website into a promo video

DivtoVid is a Claude Code plugin. Give it a URL and Claude reads the site, writes a scene script, and renders a short video, then sends it to you in the chat.

Install the plugin View on GitHub
> /divtovid https://example.com

One command, five steps

After you type /divtovid, Claude does the rest. You only choose the length.

Ask

Pass a URL, then pick 15, 30 or 60 seconds, or type your own length.

Scrape

Claude pulls the site's name, tagline, features, call to action, brand colours and images. Only what the site really says.

Script

A 4-6 scene script that adds up to your chosen length, at 30 fps and 1920×1080.

Build

A Remotion project that animates the scenes in the site's own colours and fonts.

Render & send

Claude checks sample frames, renders an MP4 and sends it straight into the chat.

Install

Pick whichever fits how you use Claude Code.

Inside a Claude Code session

Answer y to add the marketplace, then pick a scope.

/plugin install divtovid --marketplace divyanshugour/divtovid

From a shell

Works anywhere the claude CLI is installed.

claude plugin install divtovid --marketplace divyanshugour/divtovid

Claude desktop app

Click + next to the prompt box, then Plugins, then Add marketplace and enter:

divyanshugour/divtovid

Then run /divtovid https://your-site.com. To update later: claude plugin update divtovid@divtovid and restart Claude Code.

Good to know

Small, transparent, and under your control.

Just one file

The plugin is a single command file with instructions for Claude. No code, no hook, no MCP server.

You stay in control

It only acts when you type the command, and you approve commands such as npm install and the render through Claude Code's normal permissions.

Requirements

Node.js with npx. Remotion fetches its own headless Chrome and encoder on first render, so no separate ffmpeg is needed.

Network access

The site you want to promo must be reachable. In locked-down environments, allow that domain plus the package hosts Remotion needs.

Remotion licence

Videos are built with Remotion. Check its licence terms if you use it for a company.
